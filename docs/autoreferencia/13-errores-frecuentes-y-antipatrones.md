# Errores frecuentes y antipatrones

- Ampliar el alcance sin una dependencia concreta.
- Modificar archivos no relacionados.
- Modernizar JavaScript e introducir sintaxis incompatible.
- Usar APIs posteriores a Java 8.
- Renombrar IDs, parametros, actions, forwards o atributos.
- Reformatear archivos completos.
- Confundir warnings del navegador con la causa del defecto visual.
- Renderizar `div`, filas o celdas vacias por condiciones incompletas.
- Perder cambios durante merges o usar Git destructivo.
- Confiar en UTF-8 predeterminado.
- Corregir sintomas sin revisar el productor del estado.
- Desactivar nonce, permisos, validaciones o fail-closed.
- Declarar exito sin pruebas suficientes.
