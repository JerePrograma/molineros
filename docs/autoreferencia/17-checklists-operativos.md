# Checklists operativos

## Inicio
- [ ] Raiz y remoto exactos.
- [ ] Rama `main`.
- [ ] HEAD registrado.
- [ ] Cambios locales identificados.
- [ ] `origin/main` integrado.

## Bug
- [ ] Archivo de entrada identificado.
- [ ] Estado productor y consumidor localizados.
- [ ] Includes/callers directos revisados.
- [ ] Causa separada de warnings.
- [ ] Alcance no inspeccionado registrado.

## JSP
- [ ] Namespace de portlet preservado.
- [ ] IDs, names y handlers intactos.
- [ ] HTML no genera contenedores vacios.
- [ ] Salidas escapadas.
- [ ] Condiciones de permisos preservadas.

## Java
- [ ] Java 8.
- [ ] Firmas y excepciones publicas preservadas.
- [ ] Validacion y transaccion revisadas.
- [ ] Concurrencia y fail-closed preservados.

## JavaScript
- [ ] ES5.
- [ ] jQuery legacy.
- [ ] Sin globales o handlers duplicados.
- [ ] Timeouts, abort y errores tratados.

## Diff y publicacion
- [ ] ISO-8859-1 sin BOM.
- [ ] Sin mojibake.
- [ ] `git diff --check`.
- [ ] Staging por rutas exactas.
- [ ] Commit en espanol.
- [ ] Fetch previo al push.
- [ ] Push sin force.
- [ ] SHA local/remoto coincidentes.
- [ ] Informe final completo.
